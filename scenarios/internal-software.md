# 内部软件

先读 [品牌底座](../core/brand.md)。这个场景还没有专门的规范，下面只列出可以直接沿用的部分。

## 直接沿用

- 颜色和字体：[tokens.md](../core/tokens.md)。网页技术栈可直接引入 [`core/tokens.css`](../core/tokens.css)。
- 界面文字用 Sans；表格里的数值、编号用 Mono。
- 可点击的元素用 `action`。`brand` 只用于品牌识别（如标志旁、启动页），不用于普通按钮。
- 状态提示必须同时有文字，不能只靠颜色。

## 尚未定义

- 状态色板（成功、警告、错误、提示）。
- 深色模式。
- 间距和圆角。
- 按钮、表单、表格等界面组件。

## 待决定

内部软件需要大量通用界面组件，不适合从零做。可以选一套现成的开源组件库，再用上面的颜色和字体换肤。Meta 的 [Astryx](https://astryx.atmeta.com/) 支持这种做法，但它目前是测试版，且要求 React 19。是否采用尚未决定。
