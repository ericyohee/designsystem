# 社交媒体

先读 [品牌底座](../core/brand.md)。

**这份文件目前是框架。** 下面的栏目是这个场景将来要有的内容；标着“待定”的栏目还没有规则，做到这个场景时再逐项确定。待定的栏目不要自己补成规则：按“直接沿用”的部分做，并把你做的选择列出来给负责人确认。

## 直接沿用

- 颜色和字体：[tokens.md](../core/tokens.md)。
- 标志：只用官方文件。
- 白字放在紫色上时，小字用 `action` 或 `ink` 做底，只有大标题可以放在 `brand` 上。
- 橙色 `result` 只用于成绩和结果，浅色底上不做文字色。
- 技术数值和编号用 Mono，并且必须是真实的或标明为示例。
- 可参考的版面方向：Visible / Invisible、公差带。

## 规范框架

| 栏目 | 要定的内容 | 状态 |
| --- | --- | --- |
| 1. 用在哪些平台 | 发哪些平台，各自面向谁、想让对方做什么 | 待定 |
| 2. 尺寸与安全区 | 每个平台的画幅，以及会被头像、按钮、文字遮住的区域 | 待定 |
| 3. 内容类型 | 封面、单图、多图轮播、头像与主页横幅各自的用途 | 待定 |
| 4. 版式模板 | 每种内容类型的固定排法 | 待定；可参考底座里已通过的版面方向 |
| 5. 标志 | 位置、大小、周围留白、深色版还是反白版 | 待定，依赖 [品牌底座](../core/brand.md) 的标志规则 |
| 6. 颜色 | 各颜色在这个场景里占多大面积、怎么搭配 | 数值沿用底座；面积和搭配待定 |
| 7. 字体与字号 | 在手机上看得清的最小字号、标题与正文的大小关系 | 字体分工沿用底座；字号待定 |
| 8. 图片与插图 | 照片、产品图、图表的风格和处理方式 | 待定 |
| 9. 文案 | 语气、长度、话题标签的写法 | 待定 |
| 10. 文件格式与命名 | 导出格式、清晰度、文件怎么命名和存放 | 待定 |
| 11. 示例 | 做对的例子和常见错误的例子 | 待定 |
| 12. 交付前检查 | 发出去之前逐条核对的清单 | 待定 |
