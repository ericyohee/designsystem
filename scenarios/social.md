# 社交媒体

先读 [品牌底座](../core/brand.md)。这个场景还没有专门的规范，下面只列出可以直接沿用的部分。

## 直接沿用

- 颜色和字体：[tokens.md](../core/tokens.md)。
- 标志：只用官方文件。
- 白字放在紫色上时，小字用 `action` 或 `ink` 做底，只有大标题可以放在 `brand` 上。
- 技术数值和编号用 Mono，并且必须是真实的或标明为示例。
- 可参考的版面方向：Visible / Invisible、公差带。

## 尚未定义

- 各平台的尺寸和安全区。
- 封面、图文、轮播的模板。
- 标志在图上的位置和最小尺寸。
- 照片和插图的风格。
- 文案语气。
