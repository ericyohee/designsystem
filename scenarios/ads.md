# 广告投放

先读 [品牌底座](../core/brand.md)。

**这份文件目前是框架。** 下面的栏目是这个场景将来要有的内容；标着“待定”的栏目还没有规则，做到这个场景时再逐项确定。待定的栏目不要自己补成规则：按“直接沿用”的部分做，并把你做的选择列出来给负责人确认。

## 直接沿用

- 颜色和字体：[tokens.md](../core/tokens.md)。
- 标志：只用官方文件。
- 一句简短的品牌主张可以用 Display 字体；描述性的卖点用 Sans。
- 按钮和“了解更多”类文字用 `action`，不用 `brand`。
- 橙色 `result` 只用于成绩和结果，浅色底上不做文字色。
- 不出现未经验证的能力、良率、认证或客户结果。
- 广告落地页按 [网页](./web.md) 的规范做。

## 规范框架

| 栏目 | 要定的内容 | 状态 |
| --- | --- | --- |
| 1. 投放渠道与目标 | 投哪些渠道，各自面向谁、想让对方做什么 | 待定 |
| 2. 尺寸与平台限制 | 每个渠道的画幅、文件大小、文字占比等硬性要求 | 待定 |
| 3. 素材类型 | 静态图、轮播、短视频各自的用途 | 待定 |
| 4. 版式模板 | 每种素材的固定排法：主张、卖点、按钮、标志各放哪 | 待定 |
| 5. 标志 | 位置、大小、周围留白、深色版还是反白版 | 待定，依赖 [品牌底座](../core/brand.md) 的标志规则 |
| 6. 颜色 | 各颜色在这个场景里占多大面积、怎么搭配 | 数值沿用底座；面积和搭配待定 |
| 7. 字体与字号 | 缩小展示时仍看得清的最小字号 | 字体分工沿用底座；字号待定 |
| 8. 行动按钮 | 按钮文字怎么写、放在哪、长什么样 | 颜色沿用 `action`；其余待定 |
| 9. 可以说什么 | 哪些说法需要证据，数据和客户案例怎么标注来源 | 原则沿用底座“只展示真实的东西”；细则待定 |
| 10. 图片与插图 | 照片、产品图、图表的风格和处理方式 | 待定 |
| 11. 与落地页的衔接 | 广告和点进去的页面在标题、画面、颜色上怎么保持一致 | 落地页沿用 [网页](./web.md)；衔接规则待定 |
| 12. 多版本测试 | 同一条广告做几个版本时，哪些可以变、哪些不能变 | 待定 |
| 13. 文件格式与命名 | 导出格式、文件怎么命名和存放 | 待定 |
| 14. 示例 | 做对的例子和常见错误的例子 | 待定 |
| 15. 交付前检查 | 发出去之前逐条核对的清单 | 待定 |
