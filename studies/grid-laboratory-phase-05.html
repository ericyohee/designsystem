02 / EVIDENCE MAP

Which rule comes from where?

Official source statements are separated from Geniotek’s inferences and proposals; no column count or CSS value is attributed to ABCD.

SOURCE / APPLICATION

IBM Design Language

2x Grid ↗

Source: consistent divisions, margins, equal columns/rows, and gutters as structural geometry.

Geniotek experiment: compare 12 and 16 columns against one stable set of content; neither is automatically approved.

IBM Carbon

2x Grid guidelines ↗

Source: 32px default wide gutter, 16px narrow, 1px condensed; narrow/condensed allow containers to hang into gutters while text remains aligned.

Geniotek experiment: compare surface behavior without changing the sample’s text start.

Apple HIG

Layout ↗

Source: alignment makes relationships scannable; indentation communicates hierarchy; whitespace and reflow support changing content and size.

Geniotek experiment: inspect index/content separation and 390px reflow. This is an application, not Apple’s fixed grid.

ABCD / EUC

Project details ↗

Source: scale and grid symbolize planning; information develops by proportional relationships while visual design remains restrained.

Geniotek inference: minimize unnecessary grid visibility and maintain a consistent proportional structure. ABCD publishes no CSS tokens for this project.
03 / HUMAN REVIEW

Numbers cannot judge composition.

Before freezing a system, check overall visual grey, reading order, intentional exceptions, bilingual wrapping, 200% browser zoom, color/icon interplay and whether the layout remains calm with guides turned off.
